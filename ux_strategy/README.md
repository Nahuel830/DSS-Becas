# Estrategia UX - DSS-Becas

Esta carpeta contiene la documentación correspondiente a la estrategia de experiencia de usuario del proyecto DSS-Becas.

El objetivo de esta fase es definir los usuarios, necesidades y objetivos de interacción que orientan el diseño del Sistema de Soporte a Decisiones para la asignación y seguimiento de becas universitarias.

## Documento principal

Archivo:

`UX_Strategy_DSS_Becas_Fase_1.docx`

## Contenido de la estrategia UX

La documentación incluye:

- Descripción del producto.
- Identificación del problema.
- Objetivos del sistema.
- Usuarios del sistema.
- Necesidades de los usuarios.
- Objetivos de interacción.
- Propuesta de experiencia de usuario.

## Usuarios identificados

### Usuario Operativo

Personal encargado de gestionar la información de estudiantes y procesos de becas.

Funciones:

- Registrar estudiantes.
- Validar información.
- Ejecutar evaluaciones DSS.
- Gestionar solicitudes.

---

### Usuario Estratégico

Directivos encargados de analizar información para la toma de decisiones.

Funciones:

- Revisar indicadores.
- Analizar rankings.
- Aprobar recomendaciones.

---

### Usuario Final

Estudiantes universitarios que solicitan o reciben una beca.

Funciones:

- Consultar información.
- Revisar estado de solicitud.
- Conocer resultados.
