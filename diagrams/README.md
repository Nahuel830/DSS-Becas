# Diagramas DSS-Becas

Esta carpeta contiene los diagramas utilizados para representar la estructura y navegación del Sistema de Soporte a Decisiones para la asignación y seguimiento de becas universitarias.

## Diagrama incluido

### Diagrama de navegación del sistema

Archivo:

`DSS_Becas_Diagrama_Navegacion.drawio`

Representa:

- Acceso mediante Login.
- Dashboard principal.
- Gestión de estudiantes.
- Evaluación DSS.
- Gestión de becas.
- Seguimiento académico.
- Reportes.
- Administración del sistema.

## Herramienta utilizada

- Draw.io para la elaboración del diagrama.
