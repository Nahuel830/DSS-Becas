# API Estudiantes

## Registrar estudiante

Método:

POST

Endpoint:

/api/estudiantes

## Descripción

Permite registrar la información personal, académica y socioeconómica de un estudiante.

## Datos enviados

```json
{
 "nombre": "Juan Perez",
 "carrera": "Ingeniería",
 "promedio": 8.5,
 "ingreso_familiar": 500
}
