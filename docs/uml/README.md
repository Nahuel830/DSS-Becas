# Diagramas UML - DSS Becas

Esta carpeta contiene los diagramas UML desarrollados para el Sistema de Soporte a Decisiones para la Asignación y Seguimiento de Becas Universitarias.

## Diagramas incluidos

### 1. Diagrama de Casos de Uso

Representa la interacción entre los usuarios del sistema y las funcionalidades principales relacionadas con la gestión de estudiantes, evaluación de criterios y asignación de becas.

Archivo:
- casos_uso.puml
- Casos_de_uso.drawio.png


### 2. Diagrama de Clases

Representa la estructura del sistema mediante clases, atributos, relaciones y responsabilidades principales.

Archivo:
- clases.puml
- Clases.drawio.png


### 3. Diagrama de Secuencia

Describe el flujo de interacción entre los componentes del sistema durante el proceso de evaluación de estudiantes.

Archivo:
- secuencia_evaluacion.puml
- secuencia_evaluacion.png
