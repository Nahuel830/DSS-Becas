# Casos de Prueba DSS-Becas

## Objetivo

Definir los casos de prueba necesarios para validar las funcionalidades principales del sistema DSS-Becas.

---

## Caso de Prueba 01: Registro de estudiante

| Campo | Descripción |
|---|---|
| ID | CP-001 |
| Módulo | Gestión de estudiantes |
| Descripción | Registrar un nuevo estudiante en el sistema |
| Entrada | Datos personales, académicos y socioeconómicos |
| Resultado esperado | El estudiante queda almacenado correctamente |
| Estado | Exitoso |

---

## Caso de Prueba 02: Evaluación de candidato

| Campo | Descripción |
|---|---|
| ID | CP-002 |
| Módulo | Evaluación DSS |
| Descripción | Calcular el puntaje de un estudiante |
| Entrada | Información académica y socioeconómica |
| Resultado esperado | El sistema genera un puntaje DSS |
| Estado | Exitoso |

---

## Caso de Prueba 03: Asignación de beca

| Campo | Descripción |
|---|---|
| ID | CP-003 |
| Módulo | Gestión de becas |
| Descripción | Asignar una beca según criterios definidos |
| Entrada | Puntaje obtenido por el estudiante |
| Resultado esperado | El sistema recomienda una beca |
| Estado | Exitoso |

---
