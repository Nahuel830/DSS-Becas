# Componentes del Sistema

El sistema DSS-Becas se compone de los siguientes elementos principales:

1. **Frontend (Capa de Presentación)**: Interfaz de usuario para la interacción con administradores y analistas.
2. **Backend (API REST)**: Capa de servicios que procesa la lógica de negocio y los cálculos DSS.
3. **Motor DSS**: Componente encargado de evaluar los criterios académicos y sociales para emitir recomendaciones.
4. **Base de Datos**: Repositorio central de información de estudiantes, evaluaciones y becas.
