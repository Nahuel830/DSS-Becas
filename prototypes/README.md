# Prototipos UI - DSS-Becas

Esta carpeta contiene los prototipos de interfaz de usuario desarrollados para el Sistema de Soporte a Decisiones para la Asignación y Seguimiento de Becas Universitarias (DSS-Becas).

Los prototipos representan las principales pantallas del sistema y permiten visualizar la interacción entre el usuario y las funcionalidades propuestas.

## Pantallas desarrolladas

### Dashboard DSS

Vista principal del sistema donde se muestran:

- Cantidad de estudiantes evaluados.
- Candidatos recomendados.
- Estudiantes en revisión.
- Estudiantes en riesgo.
- Ranking de candidatos.
- Alertas del sistema.
- Distribución de estudiantes por estado.

Archivo:

`dashboard-dss.png`

---

### Gestión de estudiantes

Permite administrar la información de estudiantes registrados.

Incluye:

- Listado de estudiantes.
- Código del estudiante.
- Carrera.
- Estado de beca.
- Puntaje DSS.
- Búsqueda de estudiantes.

Archivo:

`gestion-estudiantes.png`

---

### Nuevo estudiante

Formulario para registrar nuevos candidatos.

Incluye:

- Datos personales.
- Datos académicos.
- Información socioeconómica.
- Solicitud de beca.
- Documentación adjunta.

Archivo:

`nuevo-estudiante.png`

---

### Evaluación DSS

Pantalla para calcular el puntaje de decisión mediante criterios ponderados:

- Rendimiento académico.
- Asistencia.
- Situación socioeconómica.
- Carga familiar.
- Condición vulnerable.

Archivo:

`evaluacion-dss.png`

---

### Detalle del estudiante

Permite consultar información específica del estudiante:

- Puntaje DSS.
- Estado de recomendación.
- Evaluación por criterios.
- Historial académico.
- Seguimiento.

Archivo:

`detalle-estudiante.png`

---

### Diagrama de navegación

Representa la estructura de navegación del sistema y la relación entre módulos.
